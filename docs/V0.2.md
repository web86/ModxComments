# v0.2 design notes

v0.2 keeps the v0.1 database schema, so existing rows need no migration.

## Edit/delete authorization
The browser receives canEdit/canDelete for rendering only. Every write is re-checked server-side: authenticated user, matching comment user_id, existing non-deleted comment, and unexpired edit window. Guest comments are not editable in v0.2 because there is no durable guest ownership credential yet.

## Turnstile
Disabled by default. web/init exposes only the site key. Create requests send the one-time token; the server sends it with the secret to Cloudflare Siteverify.

## Manager moderation
The manager connector uses MODX's regular manager bootstrap. The v0.2 CMP supports list/search/filter, published, pending, spam and soft delete.

## Events
- ModxCommentsOnCommentCreate
- ModxCommentsOnCommentUpdate
- ModxCommentsOnCommentDelete

Each event receives the xPDO comment object and the ModxComments service instance.
